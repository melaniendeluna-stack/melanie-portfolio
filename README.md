# Melanie De Luna Portfolio

A reference-inspired laboratory science portfolio built with plain HTML, CSS, and JavaScript.

## Open locally
Open `index.html` directly, or open the folder in VS Code and use Live Server.

## Main pages
- `index.html` — compact homepage with summary, portrait, and Louis Pasteur quote
- `about.html` — extended biography
- `experience.html` — Labcorp and PRL experience
- `projects.html` — research project gallery
- `skills.html` — laboratory capabilities
- `resume.html` — embedded résumé
- `contact.html` — email and LinkedIn

## Editing
Shared colors, typography, spacing, and layout are in `css/style.css`..
